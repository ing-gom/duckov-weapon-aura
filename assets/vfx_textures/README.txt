무기 오라 파티클 텍스처 폴더
================================

여기에 PNG(또는 JPG/TGA)를 넣으면 오라 디버그 패널(Ctrl+Shift+F8)의
"텍스처" 항목에서 파일 이름으로 골라 쓸 수 있습니다.

- 프리팹(.prefab)과 달리 이미지는 AssetBundle 없이 런타임에 바로 로드됩니다
  (Texture2D.LoadImage).
- 파일 이름(확장자 제외)이 그대로 프로필의 textureName 값이 됩니다.
- 패널에서 [↻] 버튼을 누르면 폴더를 다시 스캔합니다 (게임 재시작 불필요).

권장 사양
---------
- 알파 채널이 있는 PNG. 가산 합성이라 검은 부분은 자동으로 투명하게 보입니다.
- 정사각형 256x256 ~ 512x512 정도면 충분합니다.
- 플립북(스프라이트 시트)이면 패널의 "플립북 가로/세로" 칸 수를 맞춰 주세요.
  예: 4x4 시트 → 가로 4, 세로 4. FPS 0이면 파티클 수명에 맞춰 1회 재생.

어울리는 텍스처 종류
--------------------
- soft glow / radial gradient : 기본 오라 (내장 글로우와 동일 계열)
- wispy smoke, streak, ribbon : "늘리기(리본)" 옵션과 조합하면 오로라 느낌
- sparkle, star, lens flare   : 링 파티클용
- perlin / curl noise         : 노이즈 세기와 함께 흐르는 느낌

라이선스 주의
-------------
배포하는 모드에 포함되므로, 재배포 가능한 라이선스의 텍스처만 넣으세요.
