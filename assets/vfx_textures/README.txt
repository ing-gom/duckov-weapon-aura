무기 오라 파티클 텍스처 폴더
================================

여기에 PNG(또는 JPG/TGA)를 넣으면 설정 창의 [모양 고르기]와 오라 디버그
패널(Ctrl+Shift+F8)의 "텍스처" 항목에서 파일 이름으로 골라 쓸 수 있습니다.

이 폴더는 모드에 같이 실려 나갑니다 — 빌드하면 설치본과 배포 묶음 양쪽에
그대로 들어갑니다. 다만 놓이는 자리가 빌드 방식마다 다릅니다.

  게임에 바로 설치(dotnet build) : <모드>/vfx_textures
  배포 묶음(build.ps1)           : <모드>/assets/vfx_textures

모드는 두 자리를 모두 뒤지므로 어느 쪽이든 그대로 보입니다.

내 것만 쓰고 배포에는 넣고 싶지 않은 이미지는 사용자 데이터 폴더에 넣으세요.
모드를 다시 설치해도 지워지지 않습니다.

  %USERPROFILE%\AppData\LocalLow\TeamSoda\Duckov\WeaponAura\vfx_textures

- 프리팹(.prefab)과 달리 이미지는 AssetBundle 없이 런타임에 바로 로드됩니다
  (Texture2D.LoadImage).
- 파일 이름(확장자 제외)이 그대로 프로필의 textureName 값이 됩니다.
- 패널에서 [↻] 버튼을 누르면 폴더를 다시 스캔합니다 (게임 재시작 불필요).

권장 사양
---------
- 알파 채널이 있는 PNG. 가산 합성이라 검은 부분은 자동으로 투명하게 보입니다.
- 정사각형 256x256 ~ 512x512 정도면 충분합니다.
- 한 칸짜리 그림을 넣으세요. 여러 모양을 격자로 모아 놓은 그림은 칸을 나누는
  기능이 없어서, 알갱이 하나에 격자가 통째로 찍힙니다.

어울리는 텍스처 종류
--------------------
- soft glow / radial gradient : 기본 오라 (내장 글로우와 동일 계열)
- wispy smoke, streak, ribbon : "늘리기(리본)" 옵션과 조합하면 오로라 느낌
- sparkle, star, lens flare   : 링 파티클용
- perlin / curl noise         : 노이즈 세기와 함께 흐르는 느낌

라이선스 주의
-------------
배포하는 모드에 포함되므로, 재배포 가능한 라이선스의 텍스처만 넣으세요.
