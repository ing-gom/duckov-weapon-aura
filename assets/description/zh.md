# Weapon Aura

按品质变化的四种效果：**武器表面的光环**、**子弹拖尾**、**枪口火焰**、**近战挥砍**。四者都能在游戏内设置窗口中调整颜色与形态，不需要的可以关闭。

## 武器光环 — 按武器品质

不是零散粒子，而是沿武器外形延展的面（外壳），因此枪械与近战武器都会被轮廓包裹。

- **七个品质档** — 对应物品品质 1~7。9、999 之类的特殊品质可自行添加。
- **实时 3D 预览** — 显示当前手持武器，或从列表中选择的武器。可拖拽旋转，用`放大`滑块拉近，按`正面`复位。
- **12 种属性模板** — 极光 / 火焰 / 冰霜 / 剧毒 / 虚空 / 雷电 / 神圣 / 血气 / 奥术 / 等离子 / 自然 / 暗影。
- **面·波动·粒子** — 层数、延展距离、同心波动、表面粒子的数量·大小·寿命，以及拖尾。
- **留在经过的位置** — 粒子留在生成处，移动时会在路径上铺出图案。
- **光环** — 环绕武器旋转的光点。可设定数量、半径、大小、旋转与倾角，还能使用<b>与光环不同的图案</b>。
- **图层** — 再叠加粒子层，最多四层。每层可单独选择喷发位置（枪口·本体·枪管·整把武器）以及方向、颜色、形状与寿命。
- **整体强度** — 弱 / 普通 / 强。

## 子弹拖尾 — 按弹药品质

取决于已装填的弹药品质。这与武器品质是不同的轴，所以枪与子弹可以是不同颜色。

- **按品质的颜色与形态** — 头部颜色、尾部颜色、长度、粗细渐变、透明度、亮度、发光。
- **拖尾方式** — 连续的`线条`，或按固定间隔留下图形的`印记`（每米数量、大小、持续时间）。
- **子弹头部** — 隐藏游戏原版弹道，由模组直接绘制。可调形状、粗细、长宽比、亮度、颜色。
- **子弹光点** — 调整或关闭跟随子弹的光的大小、亮度与颜色。
- **动态预览** — 绘制一发子弹飞过的画面。颜色与图形取自与实际相同的来源。
- **应用对象** — 仅我的子弹 / 所有子弹。

## 枪口火焰 — 按弹药品质

与拖尾使用同一弹药品质，因此枪口炸开的颜色会顺势延续到飞行轨迹上。

- **中心白光，外围品质色** — 既像火焰，也能读出品质。
- **大小 · 持续时间 · 火星** — 向前迸射的火星数量、速度、大小都可单独设定。
- **图层** — 开火瞬间在火焰之上额外喷出粒子。
- **方式** — `仅改色` · `叠加显示` · `完全替换`。叠在游戏火焰上会让亮度翻倍，想看清颜色就用替换。
- **循环预览** — 火焰只有 0.05 秒，看一次根本来不及。以比实际更慢的间隔反复播放，让形态看得清。
- **应用对象** — 仅我的枪 / 所有枪。

## 近战挥砍 — 按武器品质

原本只有单一白色的挥砍，改为武器品质色，并沿轨迹飞溅粒子。与光环共用品质轴，两者可读作一套。

- **挥砍颜色** — 直接为弧线上色，透明度与亮度可另设。大小不改动：那是武器攻击距离的信息。
- **挥砍形状 · 飞溅形状** — 弧线上的图案与粒子形状可分别选择。
- **飞溅** — 粒子沿挥砍方向呈扁平扇形飞出。数量、大小、距离、宽度、上升、旋转、持续时间。
- **图层** — 挥砍瞬间额外喷出粒子。默认<b>沿弧线扩散</b>，正好贴合游戏绘制的挥砍。
- **三种预设** — 刀刃碎片 / 火星 / 花瓣。
- **方式** — `仅改色` · `改色 + 飞溅`（默认）· `仅飞溅`（移除游戏原版挥砍）。
- **应用对象** — 仅我的武器 / 所有武器。

## 设置窗口

从暂停菜单的`光环设置`按钮打开。顶部分页切换四种功能。

- **取色器** — 饱和度/明度方块与色相条，或以 HEX(`#FF8800`) 与 R/G/B 精确输入。
- **按品质开关** — 不想在低品质上出现效果时单独关闭该品质。
- **单把武器专属设置** — 不按品质，而是针对<b>某一把武器</b>设定。游戏内所有武器都可在列表中找到，尚未获得的也能预先设定。
- **形状选择窗口** — 内建形状、自绘形状与 `vfx_textures` 中的 PNG 都以图像呈现供你挑选。模组内附 52 张 PNG。
- **自绘形状** — 在绘制方格上画好保存后，任何分页都能选用。
- **基础 / 高级** — 常用数值与微调数值分开摆放。
- **设置分享** — 可只分享一个分页，也可把四个分页打包成一行。接收时通过输入框确认。
- **随机生成** — 颜色与形态一并随机。基于种子，满意的组合可以再现。

## 使用方法

1. 按 `ESC` 打开暂停菜单，点击`光环设置`。
2. 在顶部选择`武器光环` · `子弹拖尾` · `枪口火焰` · `近战挥砍`分页。
3. 选择品质，调整颜色与形态后点`保存`。四个分页会一起保存。

保存的设置会在下次启动时自动载入。`恢复默认`只还原当前分页。窗口开启期间瞄准与射击被阻断，按 `ESC` 只关闭窗口。
