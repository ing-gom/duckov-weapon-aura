# Weapon Aura

新增四种按品质变化的效果：**从武器表面扩散的光环**、**子弹飞行时留下的拖尾**、**枪口炸开的火焰**，以及**挥动近战武器时的挥砍效果**。四者都可以在游戏内设置窗口中调整颜色与形态，不需要的可以单独关闭。

## 武器光环 — 按武器品质

光环会**从武器表面向外扩散**。它不是一团粒子，而是贴合武器外形的光壳，因此枪械和近战武器都会被自己的轮廓包裹。

- **七个品质等级** — 对应物品品质 1~7。品质 9、999 等特殊与制作等级可自行添加并单独设置。
- **实时 3D 预览** — 直接显示当前手持的武器。选择等级后颜色立即呈现，可拖动旋转或缩放查看。
- **12 种属性模板** — 极光 / 火焰 / 冰霜 / 剧毒 / 虚空 / 电击 / 神圣 / 血气 / 奥术 / 等离子 / 自然 / 暗影。一键更换整体配色与动态。
- **光壳、波纹、粒子** — 层数、扩散距离、同心波纹、表面粒子的数量与大小、寿命，以及拖尾。
- **留在经过的位置** — 开启后粒子不再跟随武器，而是留在生成处，移动时会在路径上铺出图案。关闭则只贴着武器移动。
- **光环** — 环绕武器旋转的光点。可设定数量、半径、大小、旋转速度与倾角，还能使用<b>与光环不同的图案</b>（爱心、星形等）。
- **序列帧** — 将拼贴图逐格播放。把 4×4 拼贴图放入 `assets/vfx_textures` 并设定格数即可。
- **整体强度** — 弱 / 普通 / 强。

## 子弹拖尾 — 按弹药品质

子弹会带上**与已装填弹药品质相符的彩色尾迹**。武器品质与弹药品质是两条独立的轴，因此枪和子弹可以是不同的颜色。

- **按品质设定颜色与形态** — 头部颜色、尾部颜色、拖尾长度、头尾粗细、不透明度、亮度、发光。
- **动态预览** — 按当前设置演示一发子弹飞过的样子。时间轴与实际一致，可以直观看到「长度 0.3 秒」在画面上能留多远。
- **应用对象** — 只对我的子弹，或包含所有人的子弹。

## 枪口火焰 — 按弹药品质

开火瞬间**枪口会炸开品质颜色的火焰**。它与拖尾使用同一条弹药品质轴，因此枪口炸开的颜色会顺势延伸成飞行的拖尾。

- **中心炽白，外围呈现品质色** — 既像真实火焰，又能读出品质。
- **大小 · 持续时间 · 火星** — 向前迸射的火星数量、速度、大小都可单独设定。
- **隐藏游戏原本的火焰** — 叠加在原本的火焰之上会让亮度翻倍。想让颜色更纯净时开启。
- **以连射速度循环的预览** — 火焰只有 0.05 秒左右，只放一次根本看不清。这里按实战中连射的样子呈现。

## 近战挥砍 — 按武器品质

挥动近战武器时的**挥砍效果原本只有白色**。此功能将其改为武器品质对应的颜色，并让粒子沿挥砍轨迹飞溅。它与武器光环使用同一条品质轴，因此包裹武器的颜色和挥出的颜色是同一套。

- **挥砍颜色** — 直接为挥出的弧线上色，不透明度与亮度可分别设置。**不会改动大小** — 挥砍的大小体现该武器的攻击距离，放大会让画面与实际可及范围不符。
- **挥砍形状** — 更换弧线上的图案：内置形状（光晕、爱心、星形、菱形、圆环、闪光）、自绘形状，或放入 `assets/vfx_textures` 的 PNG。
- **飞溅** — 粒子沿挥砍方向呈扁平扇形飞出。数量、大小、距离、扇形宽度、上升高度、旋转与持续时间均可单独调整。
- **飞溅形状** — 与枪口火焰共用同一份列表：内置形状（光晕、爱心、星形、菱形、圆环、闪光）、自绘形状，以及放入 `assets/vfx_textures` 的 PNG。
- **三种预设** — 刀刃碎片 / 火星 / 花瓣。一次设定六七个数值。
- **方式** — `仅改颜色` · `颜色 + 飞溅`（默认） · `仅飞溅`（移除游戏原本的挥砍效果）。
- **应用对象** — 仅我的武器 / 所有武器。

## 设置窗口

从暂停菜单的 `光环设置` 按钮打开，使用游戏本身的字体与配色。顶部分页在四种效果之间切换。

- **取色器** — 在饱和度/明度方块与色相条上直接取色，也可用 HEX（`#FF8800`）或 R/G/B 精确输入。
- **按品质开关** — 不希望低品质带效果时，可单独关闭该品质。
- **自绘形状** — 武器光环、枪口火焰、近战挥砍三个分页都有绘制方格。画好保存后，三处都能选用该形状。（子弹拖尾不使用形状）
- **基础 / 高级** — 四个分页都将常用值与微调值分开。初次使用只看基础即可。
- **设置分享** — 将当前编辑的品质设置复制为一行到剪贴板，粘贴即可套用。
- **随机生成** — 颜色与形态一并随机。基于种子，遇到满意的组合记下种子即可复现。

## 使用方法

1. 游戏中按 `ESC` 打开暂停菜单。
2. 点击 `光环设置`。
3. 在窗口上方选择 `武器光环`、`子弹拖尾`、`枪口火焰` 或 `近战挥砍` 分页。
4. 选择品质，调整颜色与形态，然后按 `保存设置`。保存会同时写入四个分页。

保存的设置会在下次启动时自动载入。`恢复默认` 只会重置当前所在的分页。窗口开启期间会屏蔽瞄准与射击，按 `ESC` 只会关闭窗口。
