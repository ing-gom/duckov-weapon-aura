# Weapon Aura

依品質變化的四種效果：**武器表面的光環**、**子彈拖尾**、**槍口火焰**、**近戰揮砍**。四者都能在遊戲內設定視窗中調整顏色與形態，不需要的可以關閉。

## 武器光環 — 依武器品質

不是零散粒子，而是沿武器外形延展的面（外殼），因此槍械與近戰武器都會被輪廓包裹。

- **七個品質階** — 對應物品品質 1~7。9、999 之類的特殊品質可自行新增。
- **即時 3D 預覽** — 顯示目前手持武器，或從清單中選擇的武器。可拖曳旋轉，用`放大`滑桿拉近，按`正面`復位。
- **12 種屬性範本** — 極光 / 火焰 / 冰霜 / 劇毒 / 虛空 / 雷電 / 神聖 / 血氣 / 奧術 / 電漿 / 自然 / 暗影。
- **面·波動·粒子** — 層數、延展距離、同心波動、表面粒子的數量·大小·壽命，以及拖尾。
- **留在經過的位置** — 粒子留在生成處，移動時會在路徑上鋪出圖案。
- **光環** — 環繞武器旋轉的光點。可設定數量、半徑、大小、旋轉與傾角，還能使用<b>與光環不同的圖案</b>。
- **圖層** — 再疊加粒子層，最多四層。每層可單獨選擇噴發位置（槍口·本體·槍管·整把武器）以及方向、顏色、形狀與壽命。
- **整體強度** — 弱 / 普通 / 強。

## 子彈拖尾 — 依彈藥品質

取決於已裝填的彈藥品質。這與武器品質是不同的軸，所以槍與子彈可以是不同顏色。

- **依品質的顏色與形態** — 頭部顏色、尾部顏色、長度、粗細漸變、透明度、亮度、發光。
- **拖尾方式** — 連續的`線條`，或按固定間隔留下圖形的`印記`（每米數量、大小、持續時間）。
- **子彈頭部** — 隱藏遊戲原版彈道，由模組直接繪製。可調形狀、粗細、長寬比、亮度、顏色。
- **子彈光點** — 調整或關閉跟隨子彈的光的大小、亮度與顏色。
- **動態預覽** — 繪製一發子彈飛過的畫面。顏色與圖形取自與實際相同的來源。
- **套用對象** — 僅我的子彈 / 所有子彈。

## 槍口火焰 — 依彈藥品質

與拖尾使用同一彈藥品質，因此槍口炸開的顏色會順勢延續到飛行軌跡上。

- **中心白光，外圍品質色** — 既像火焰，也能讀出品質。
- **大小 · 持續時間 · 火星** — 向前迸射的火星數量、速度、大小都可單獨設定。
- **圖層** — 開火瞬間在火焰之上額外噴出粒子。
- **方式** — `僅改色` · `疊加顯示` · `完全替換`。疊在遊戲火焰上會讓亮度翻倍，想看清顏色就用替換。
- **循環預覽** — 火焰只有 0.05 秒，看一次根本來不及。以比實際更慢的間隔反覆播放，讓形態看得清。
- **套用對象** — 僅我的槍 / 所有槍。

## 近戰揮砍 — 依武器品質

原本只有單一白色的揮砍，改為武器品質色，並沿軌跡飛濺粒子。與光環共用品質軸，兩者可讀作一套。

- **揮砍顏色** — 直接為弧線上色，透明度與亮度可另設。大小不改動：那是武器攻擊距離的資訊。
- **揮砍形狀 · 飛濺形狀** — 弧線上的圖案與粒子形狀可分別選擇。
- **飛濺** — 粒子沿揮砍方向呈扁平扇形飛出。數量、大小、距離、寬度、上升、旋轉、持續時間。
- **圖層** — 揮砍瞬間額外噴出粒子。預設<b>沿弧線擴散</b>，正好貼合遊戲繪製的揮砍。
- **三種預設** — 刀刃碎片 / 火星 / 花瓣。
- **方式** — `僅改色` · `改色 + 飛濺`（預設）· `僅飛濺`（移除遊戲原版揮砍）。
- **套用對象** — 僅我的武器 / 所有武器。

## 設定視窗

從暫停選單的`光環設定`按鈕開啟。頂部分頁切換四種功能。

- **取色器** — 飽和度/明度方塊與色相條，或以 HEX(`#FF8800`) 與 R/G/B 精確輸入。
- **依品質開關** — 不想在低品質上出現效果時單獨關閉該品質。
- **單把武器專屬設定** — 不依品質，而是針對<b>某一把武器</b>設定。遊戲內所有武器都可在清單中找到，尚未取得的也能預先設定。
- **形狀選擇視窗** — 內建形狀、自繪形狀與 `vfx_textures` 中的 PNG 都以圖像呈現供你挑選。模組內附 52 張 PNG。
- **自繪形狀** — 在繪製方格上畫好儲存後，任何分頁都能選用。
- **基礎 / 進階** — 常用數值與微調數值分開擺放。
- **設定分享** — 可只分享一個分頁，也可把四個分頁打包成一行。接收時透過輸入框確認。
- **隨機生成** — 顏色與形態一併隨機。基於種子，滿意的組合可以再現。

## 使用方式

1. 按 `ESC` 開啟暫停選單，點選`光環設定`。
2. 在頂部選擇`武器光環` · `子彈拖尾` · `槍口火焰` · `近戰揮砍`分頁。
3. 選擇品質，調整顏色與形態後點`儲存`。四個分頁會一起儲存。

儲存的設定會在下次啟動時自動載入。`還原預設`只還原目前分頁。視窗開啟期間瞄準與射擊被阻斷，按 `ESC` 只關閉視窗。
