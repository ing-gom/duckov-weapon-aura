# Weapon Aura

光環會**從武器表面向外擴散**。它不是一團粒子，而是貼合武器外形的光殼，因此槍械與近戰武器都會被自己的輪廓包覆。

## 特色

- **依品質區分的光環** — 預設提供對應物品品質 1~7 的七個等級。品質 9、999 等特殊與製作等級可自行新增並單獨設定。
- **遊戲內設定視窗** — 從暫停選單的 `光環設定` 按鈕開啟，使用遊戲本身的字型與配色。
- **即時 3D 預覽** — 直接顯示目前手持的武器。選擇等級後顏色立即呈現，可拖曳旋轉或縮放檢視。
- **取色器** — 在飽和度/明度方塊與色相條上直接取色，也可用 HEX（`#FF8800`）或 R/G/B 精確輸入。
- **12 種屬性範本** — 極光 / 火焰 / 冰霜 / 劇毒 / 虛空 / 電擊 / 神聖 / 血氣 / 奧術 / 電漿 / 自然 / 暗影。一鍵更換整體配色與動態。
- **粒子與拖尾** — 可調整表面粒子的數量、大小與壽命，並依需求開啟拖尾。
- **依品質開關** — 不希望低品質武器帶光環時，可單獨關閉該品質。
- **整體強度** — 弱 / 普通 / 強。
- **隨機產生** — 一鍵產生協調的配色與相符的節奏。

## 使用方式

1. 遊戲中按 `ESC` 開啟暫停選單。
2. 點擊 `光環設定`。
3. 選擇品質，調整顏色與型態，然後按 `儲存設定`。

已儲存的設定會在下次啟動時自動載入，隨時可用 `回復預設` 回到初始狀態。視窗開啟期間會阻擋瞄準與射擊，按 `ESC` 只會關閉視窗。
