# Weapon Aura

新增四種依品質變化的效果：**從武器表面擴散的光環**、**子彈飛行時留下的拖尾**、**槍口炸開的火焰**，以及**揮動近戰武器時的揮砍效果**。四者都可以在遊戲內設定視窗中調整顏色與型態，不需要的可以單獨關閉。

## 武器光環 — 依武器品質

光環會**從武器表面向外擴散**。它不是一團粒子，而是貼合武器外形的光殼，因此槍械與近戰武器都會被自己的輪廓包覆。

- **七個品質等級** — 對應物品品質 1~7。品質 9、999 等特殊與製作等級可自行新增並單獨設定。
- **即時 3D 預覽** — 直接顯示目前手持的武器。選擇等級後顏色立即呈現，可拖曳旋轉或縮放檢視。
- **12 種屬性範本** — 極光 / 火焰 / 冰霜 / 劇毒 / 虛空 / 電擊 / 神聖 / 血氣 / 奧術 / 電漿 / 自然 / 暗影。一鍵更換整體配色與動態。
- **光殼、波紋、粒子** — 層數、擴散距離、同心波紋、表面粒子的數量與大小、壽命，以及拖尾。
- **整體強度** — 弱 / 普通 / 強。

## 子彈拖尾 — 依彈藥品質

子彈會帶上**與已裝填彈藥品質相符的彩色尾跡**。武器品質與彈藥品質是兩條獨立的軸，因此槍與子彈可以是不同的顏色。

- **依品質設定顏色與型態** — 頭部顏色、尾部顏色、拖尾長度、頭尾粗細、不透明度、亮度、發光。
- **動態預覽** — 依目前設定演示一發子彈飛過的樣子。時間軸與實際一致，可以直觀看到「長度 0.3 秒」在畫面上能留多遠。
- **套用對象** — 只對我的子彈，或包含所有人的子彈。

## 槍口火焰 — 依彈藥品質

開火瞬間**槍口會炸開品質顏色的火焰**。它與拖尾使用同一條彈藥品質軸，因此槍口炸開的顏色會順勢延伸成飛行的拖尾。

- **中心熾白，外圍呈現品質色** — 既像真實火焰，又能讀出品質。
- **大小 · 持續時間 · 火星** — 向前迸射的火星數量、速度、大小都可單獨設定。
- **隱藏遊戲原本的火焰** — 疊加在原本的火焰之上會讓亮度加倍。想讓顏色更純淨時開啟。
- **以連射速度循環的預覽** — 火焰只有 0.05 秒左右，只放一次根本看不清。這裡按實戰中連射的樣子呈現。

## 近戰揮砍 — 依武器品質

揮動近戰武器時的**揮砍效果原本只有白色**。此功能將其改為武器品質對應的顏色，並讓粒子沿揮砍軌跡飛濺。它與武器光環使用同一條品質軸，因此包覆武器的顏色和揮出的顏色是同一套。

- **揮砍顏色** — 直接為揮出的弧線上色，不透明度與亮度可分別設定。**不會改動大小** — 揮砍的大小體現該武器的攻擊距離，放大會讓畫面與實際可及範圍不符。
- **揮砍形狀** — 更換弧線上的圖案：內建形狀（光暈、愛心、星形、菱形、圓環、閃光）、自繪形狀，或放入 `assets/vfx_textures` 的 PNG。
- **飛濺** — 粒子沿揮砍方向呈扁平扇形飛出。數量、大小、距離、扇形寬度、上升高度、旋轉與持續時間皆可單獨調整。
- **飛濺形狀** — 與槍口火焰共用同一份清單：內建形狀（光暈、愛心、星形、菱形、圓環、閃光）、自繪形狀，以及放入 `assets/vfx_textures` 的 PNG。
- **三種預設** — 刀刃碎片 / 火星 / 花瓣。一次設定六七個數值。
- **方式** — `僅改顏色` · `顏色 + 飛濺`（預設） · `僅飛濺`（移除遊戲原本的揮砍效果）。
- **套用對象** — 僅我的武器 / 所有武器。

## 設定視窗

從暫停選單的 `光環設定` 按鈕開啟，使用遊戲本身的字型與配色。頂部分頁在四種效果之間切換。

- **取色器** — 在飽和度/明度方塊與色相條上直接取色，也可用 HEX（`#FF8800`）或 R/G/B 精確輸入。
- **依品質開關** — 不希望低品質帶效果時，可單獨關閉該品質。
- **自繪形狀** — 武器光環、槍口火焰、近戰揮砍三個分頁都有繪製方格。畫好儲存後，三處都能選用該形狀。（子彈拖尾不使用形狀）
- **隨機產生** — 顏色與型態一併隨機。基於種子，遇到滿意的組合記下種子即可重現。

## 使用方式

1. 遊戲中按 `ESC` 開啟暫停選單。
2. 點擊 `光環設定`。
3. 在視窗上方選擇 `武器光環`、`子彈拖尾`、`槍口火焰` 或 `近戰揮砍` 分頁。
4. 選擇品質，調整顏色與型態，然後按 `儲存設定`。儲存會同時寫入四個分頁。

已儲存的設定會在下次啟動時自動載入。`回復預設` 只會重設目前所在的分頁。視窗開啟期間會阻擋瞄準與射擊，按 `ESC` 只會關閉視窗。
